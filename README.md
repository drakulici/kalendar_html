# HTML Calendar
A simple calendar built with HTML as a first web development lesson.
## Description
A static HTML page that displays a calendar layout. Created as an introductory exercise to learn HTML structure and table elements.
## Getting Started
Just open `index.html` in any web browser.
open index.html   # macOS
xdg-open index.html   # Linux
start index.html   # Windows
## What I Learned
- Basic HTML document structure (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- Working with HTML tables (`<table>`, `<tr>`, `<td>`, `<th>`)
- Organizing content with headings and structure
## Built With
- Plain HTML (no frameworks or libraries)
